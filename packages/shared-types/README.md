# Shared Domain Types & Contracts (packages/shared-types)

TypeScript interfaces and type declarations shared across all apps and backend:
- Domain entities (Customer, FaceEnrollment, RFIDCard, RateChart, MilkCollection, LedgerTransaction, MonthlyBill)
- API Request / Response DTOs
- Sync payload & event types
- Enums (`MilkCategory`, `CustomerStatus`, `IdentificationMethod`, `TransactionType`, `SessionType`)
