# Customer Mobile Application (apps/customer-mobile)

Farmer self-service mobile application built with React Native and Expo:
- Secure customer authentication (Mobile OTP / PIN)
- Digital passbook & real-time customer ledger
- Detailed daily milk collection slips (Quantity, Fat %, SNF %, Rate, Total Amount)
- Historical Cow & Buffalo deliveries
- Feed purchase debits & advance balance
- Monthly settlement bills & downloadable statements
- Real-time notifications & support

*Implementation scheduled for Phase 18.*
