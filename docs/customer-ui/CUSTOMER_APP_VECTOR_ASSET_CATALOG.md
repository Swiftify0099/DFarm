## 1. Vector Design Philosophy

To fulfill the strict mandate:
- **No generic emojis** as icons or indicators.
- **No stock internet graphics** or raster clip-art.
- **100% original, scalable SVG vector artwork** styled specifically with DFarm brand tokens (`#FF6A00`, `#F58A38`, `#FFE9DC`, `#211B18`).
