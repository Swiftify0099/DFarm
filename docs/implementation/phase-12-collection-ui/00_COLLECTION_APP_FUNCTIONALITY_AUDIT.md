## 3. Critical Architectural Constraints

1. **Dairy Tenant Scoping**: All API calls inject `X-Dairy-Id` and `Authorization: Bearer <token>`. Multi-tenant boundaries must never leak patron or collection data across cooperatives.
2. **Hardware Lifecycles**: Video stream, ONNX sessions (`ort.InferenceSession`), Serial port event listeners (`RfidReaderDriver`, `ScaleDriver`, `MilkAnalyzerDriver`), and Web Speech synthesizer must NOT be recreated or re-initialized on component re-renders.
3. **Idempotent Transactions**: All intakes generate a unique idempotency key (`TXN-<uuid>`). Duplicate submissions are rejected by backend and IndexedDB.
4. **Biological Bounds**: Valid milk intake strictly requires `2.0 <= FAT <= 15.0`, `6.0 <= SNF <= 12.0`, `weight > 0.00`, and `scaleStable === true`.
5. **Conflict Protection**: Simultaneous camera and RFID detections for distinct farmer IDs must trigger a hard lock with supervisor override required.
