# Central Backend API & Sync Gateway (services/backend)

Node.js & TypeScript REST API service:
- Authentication & Role-Based Access Control (RBAC)
- Customer identity lifecycle & authorization
- Rate chart engine & historical snapshot management
- Two-way offline synchronization gateway (Push/Pull with idempotent cursors)
- Customer accounting & monthly billing engine
- Notification & WhatsApp message dispatchers

*Implementation scheduled for Phase 04 - Phase 05.*
